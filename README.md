# Crux

An adaptive tutor for students, self-learners and professionals. It teaches a topic, typed or from your own lesson, until you understand it properly, and does not call it mastered until you have proven it.

## Status

Crux is being re-specified from scratch. The plan and every decision so far live in the pinned issue [Wayfinder map: Crux v1 respec](https://github.com/calmxz/Crux/issues/661); the vocabulary is in [`GLOSSARY.md`](GLOSSARY.md).

The code in this repository is the previous version, kept frozen as a reference until the new spec is compared against it. To run it, see [`backend/README.md`](backend/README.md) (which also covers typechecking) and [`frontend/README.md`](frontend/README.md); its deployment and operations docs are under [`docs/`](docs/) (`auth/`, `db/`, `deploy/`, `security/`). Its product and design docs (the old README, `PRODUCT.md`, `DESIGN.md`, `docs/decisions.md`, `docs/reference.md`, the old v1 design spec) were removed on 2026-10-20; read them with `git show e68424e:<path>`.
